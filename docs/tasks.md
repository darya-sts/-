# Задачи: канбан, категории, вложения и память ботов

Статический фронт Forge Mill (Next.js `output: "export"`). Сервера и БД нет: задачи, канбаны и память лежат в `localStorage`, файлы — в IndexedDB.

## Виды

- **Список** — карточки слева, деталь справа.
- **Канбан** — колонки по общим статусам. Перетаскивание меняет статус (`@dnd-kit/core`).
- Режим и активный канбан пишутся в `localStorage` (`forgemill-settings`) и в URL (`?view=kanban&board=board-all`).

## Канбаны и категории

Вкладки: «Все задачи», «Без категории», направления (Разработка / Маркетинг / Дизайн).
«+ Канбан» создаёт доску и категорию. «Категории» — переименовать/удалить.

Задача без категории попадает в «Без категории».

## Вложения

В карточке задачи: файл/изображение до 25 МБ (IndexedDB) и ссылка (URL + заголовок, если CORS позволяет). Превью картинок, скачивание файлов.

## Бот-исполнитель

Список из конфигурации проекта: TaskBot, MarvinBot, Cursor Agent, Architect, либо своё имя. Cursor Cloud API в статическом приложении недоступен.

## Память

«Сохранить в память» собирает JSON+Markdown (описание, чек-лист, чат, вложения) в `forgemill-task-memory`, скачивает файл `memory/tasks/…md`. Бот при команде ищет похожие записи и ссылается на них.
