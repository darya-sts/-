# Figma + Cursor: что сделать руками

Агент **не может** залогиниться в ваш Figma и нажать Allow. Это делаете вы один раз. После этого в чате Cursor работают команды `/figma-wireframe` → `/figma-hifi` → `/figma-implement`.

## Что уже лежит в репозитории

- Подключение MCP: `.cursor/mcp.json` (сервер `https://mcp.figma.com/mcp`)
- Правило агента: `.cursor/rules/figma-workflow.mdc`
- Команды: `.cursor/commands/figma-wireframe.md`, `figma-hifi.md`, `figma-implement.md`
- Стек главной (фаза 0): раздел ниже

## Ваши шаги

### 1. Проверьте Figma

1. Откройте [figma.com](https://www.figma.com) своим аккаунтом.
2. В настройках команды посмотрите **seat**. Для рисования из Cursor нужен **Full**. Dev seat почти только читает чужие файлы.
3. Создайте новый файл, например `Forge Mill — Design`.
4. Справа сверху Share: себе (или агенту) право **can edit**.
5. Скопируйте ссылку из адресной строки браузера.

### 2. Подключите Figma к Cursor на своём компьютере

Облачный агент это не сделает: OAuth откроется у вас в браузере.

1. Откройте **этот репозиторий в Cursor Desktop** (не только в браузере агента).
2. В чате Agent напишите: `/add-plugin figma`
3. Либо: Cursor Settings → MCP → должен появиться сервер `figma`. Нажмите **Connect** и разрешите доступ.
4. В списке инструментов MCP должны быть запись на холст (`use_figma`) и чтение макета.

Если Connect к remote MCP не открывается — напишите в чат Cursor. Временный обход через Personal Access Token **не рисует** макеты, только читает.

### 3. Проверка «пинга»

Новый чат Agent, вставьте ссылку на файл и текст:

```text
По этой ссылке на Figma создай на странице 01 Wireframes серый фрейм 400×200 с текстом Ping. Больше ничего.
```

Откройте файл в Figma. Есть фрейм Ping — контур живой. Нет — вернитесь к шагу 2.

### 4. Прототип главной

В чате Agent вызовите команду **`/figma-wireframe`** и снова вставьте ссылку на файл.

Смотрите страницу `01 Wireframes`. Пишите правки обычным языком. Когда ок — отдельным сообщением:

```text
УТВЕРЖДАЮ ПРОТОТИП
```

Другие слова («ок», «норм», «давай дальше») агент не считает согласием.

### 5. Превью (hi-fi)

Команда **`/figma-hifi`**. Смотрите страницу `02 Hi-Fi`. Правки текстом. Когда ок:

```text
УТВЕРЖДАЮ ПРЕВЬЮ
```

И приложите ссылку на фрейм (ПКМ по фрейму → Copy link to selection).

### 6. Вёрстка в код

Команда **`/figma-implement`**. Агент правит файлы в репозитории. Коммит — только если вы явно попросите.

## Фаза 0 — стек этого проекта (уже разобран)

| Что | Как у нас |
|---|---|
| Приложение | Forge Mill, кабинет контент-фабрики |
| Стек | Next.js 16 App Router, React 19, Tailwind v4, shadcn / Base UI |
| Сборка | `output: "export"` (статика) |
| Главная | `src/app/page.tsx` — «Обзор фабрики» |
| Оболочка | `src/components/app-shell.tsx` — серый сайдбар, группы Обзор / Управление |
| Палитра | canvas `#e6e9ec`, sidebar `#ECEFF1`, карточки `#dceef8`, кнопки `#0b66c3` |
| Шрифт | TT Commons (`src/fonts/`), в Figma MCP кастомный шрифт может не загрузиться — тогда Inter |
| Не ломать | Задачи, Агенты, Промты, Vault; на live ещё MarvinBot и Architecture |

Смысл главной для прототипа: шапка с заголовком «Обзор фабрики», KPI-карточки, баннер дедлайна, график кассы, CTA «План на 6 месяцев» и «Каталог». Не лендинг-маркетинг, а **кабинет**.

## Чего не ждать

- Cursor не откроет Figma «сам по аккаунту» без Connect.
- REST-токен Figma не заменит шаг 2.
- Картинки и часть шрифтов агент на холст пока не кладёт (бета MCP).
- Write-to-canvas позже станет платной услугой Figma; сейчас бета.
