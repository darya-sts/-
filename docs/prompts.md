# Промты (Prompt Studio)

Статический раздел кабинета (`output: "export"`). Nest/Prisma из pre-rollback снимка не переносились: фронт работает в браузере.

- Каталог агентов и моделей: `src/data/prompts.ts`
- Черновики и задания: `localStorage` `forgemill-prompts` / `forgemill-prompt-tasks`
- Память: `forgemill-prompt-memory`
- Карта направлений: `forgemill-prompt-direction-map` (правки встроенных + свои направления)
- PDF: печатный HTML (Save as PDF) + скачивание Markdown

Маршрут: `/prompts/`

## Направления

При создании запроса выбирается одно или несколько направлений: Дизайн, Маркетинг, Консультации, Сбор информации, Разработка, Администрирование. Теги пишутся в промт и хранятся в истории.

Перед делегированием оркестратор (правила кабинета, без LLM API) рекомендует агентов, навыки, правила и модель по карте. Рекомендованные агенты и модель подсвечиваются и сразу отмечаются; список можно поправить вручную.

Если текст запроса не совпадает с тегами, кабинет предлагает оставить теги, сменить на распознанные или смешать. Автоматически направление не меняется.

История фильтруется по направлениям. Карту можно дополнять во вкладке «Карта».
