# Forge Mill

Операционная система соло-фабрики контента: сетка YouTube + X (Twitter) + Telegram на англоязычную аудиторию. Цель — **$1 000–2 000 чистыми к шестому месяцу**, без фермы из двенадцати однотипных каналов.

Это не генератор роликов. Это плейбук: каталог инструментов (с пометками MCP под Cursor), проверяемые ниши с высоким CPM, недельный план на 6 месяцев, правила монетизации лета 2026 и финансовая модель.

## Зачем это существует

С августа 2026 три платформы одновременно ужесточили «фабрики»:

- **YouTube** 1 февраля 2027 удваивает вход в рекламу для новых каналов (8 000 часов или 20 млн Shorts). Сейчас ещё 4 000 часов / 10 млн Shorts.
- **X** закрыл старый ads revenue share и платит через Original Content Rewards — только оригинальный контент, не автопостинг.
- **Telegram** платит 50% ads с 1 000 подписчиков публичного канала и Stars (~$0.013) с холдом 21 день.

Плейбук заточен под человека с подпиской Cursor: агент пишет сценарии и дергает MCP, вы утверждаете тезис на X и голос/монтаж.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS v4 + shadcn/ui
- Данные плейбука в `src/data/`

## Запуск

```bash
npm install
npm run dev
```

Локальный dev-сервер слушает `http://127.0.0.1:43147`. Этот адрес работает только на машине, где запущен процесс — не на Timeweb.

Сборка и прод:

```bash
npm run build
npm start
```

`npm start` слушает `0.0.0.0` и порт из `PORT` (по умолчанию 3000 — так Timeweb App Platform / `next start` и ждут). Локально как раньше:

```bash
PORT=43147 npm start
```

Для Timeweb Cloud App Platform в корне есть `Dockerfile` (контейнер слушает `0.0.0.0:8080`, healthcheck `GET /health`). Тип приложения: **Dockerfile** или **Next.js с SSR**, не статический frontend.

## Деплой в Timeweb Cloud

1. Репозиторий: GitHub `darya-sts/-`, ветка с этим кодом.
2. Тип: Dockerfile (предпочтительно) или Next.js + SSR, команда запуска `npm start`.
3. После деплоя открывайте технический домен `*.twc1.net` / `*.timeweb.cloud` по HTTPS, не `http://127.0.0.1:43147`.

## Честно про $1–2k

В **базовом** сценарии месяц 6 даёт около $1 430 чистыми: партнёрки и цифровой продукт несут больше, чем AdSense. Консервативный сценарий к $1k не дотягивает. Агрессивный требует попадания в YPP в Q4 2026 и US-гео.

Цифры CPM/RPM — отраслевые диапазоны 2026, не прогноз вашего канала. Цены инструментов — публичные тарифы на август 2026, без налогов и промо.
